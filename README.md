# 스키 게임

눈길에서 적과 떨어지는 바위를 피하며 가능한 한 오래 살아남는 2D 웹 게임입니다.


##플레이하기
 [스키 게임 플레이하기](https://sayoon0212.github.io/my-game/)

![alt text](screenshot-2.png)

## 조작법

| 키 | 동작 |
|---|---|
| 아무 키 | 시작 화면에서 게임 시작 |
| 방향키 | 플레이어 이동 |
| 터치 | 시작 화면에서 터치해 시작하고, 누른 채 드래그해 이동 |
| M | 효과음 음소거 켜기/끄기 |
| R | 게임 오버 후 재시작 |
| D | 디버그 표시와 충돌 판정 상자 켜기/끄기 |

## 규칙
- 목표: 장애물들을 피해 오래 스키 타기.
- 점수: 떠 있는 아이템들을 먹으며 오래있으면 오름.
- 게임 오버: 장애물에 맞으면 게임 오버.

## 모바일
(지원함 / PC에서 방향키로 플레이 권장)

##개발 환경
- 순수 HTML / CSS / JavaScript (Canvas)
- 부 라이브러리 없음
- 에디터: VS Code
- 사용한 AI 도구: (Chat gpt)


## 사용한 에셋

| 에셋 | 사용 위치 / 상태 | 제작자 및 출처 주소 | 라이선스 |
|---|---|---|---|
| 스키어, 적, 바위, 아이템, 배경 그림 | `script.js`에서 Canvas 도형으로 그림 | 직접 제작 — [`script.js`](./script.js), 외부 출처 주소 없음 | 직접 제작 (외부 라이선스 없음) |
| `hit.mp3` | 적 또는 바위 충돌 효과음 (게임에서 사용) | AI 생성·절차 합성, 프로젝트 내부 파일 — 외부 출처 주소 없음 | AI 생성물 (외부 라이선스 없음) |
| `point.mp3` | 아이템 획득 효과음 (게임에서 사용) | AI 생성·절차 합성 WAV에서 변환, 프로젝트 내부 파일 — 외부 출처 주소 없음 | AI 생성물 (외부 라이선스 없음) |
| `hit.wav` | 충돌 효과음 원본 (보관용, 게임에서 직접 사용하지 않음) | AI 생성·절차 합성, 프로젝트 내부 파일 — 외부 출처 주소 없음 | AI 생성물 (외부 라이선스 없음) |
| `item-collect.wav` | 아이템 획득 효과음 원본 (보관용, 게임에서 직접 사용하지 않음) | AI 생성·절차 합성, 프로젝트 내부 파일 — 외부 출처 주소 없음 | AI 생성물 (외부 라이선스 없음) |

외부 이미지·오디오 에셋: **외부 에셋 없음 (도형으로 직접 제작)**.

## 실행

`index.html`을 브라우저에서 열어 플레이합니다. 효과음 파일은 `index.html`, `script.js`와 같은 폴더에 있어야 합니다.

앞으로 하고 싶은 것: 
아이템들을 다른 생김새로도 넣고 싶다.
장애물 속도가 조금 느리다.
